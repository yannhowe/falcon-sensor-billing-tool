📖 How FCS Licensing Works

28-Day Rolling Average

Formula: Sum of 672 hourly counts ÷ 672

Each sensor active in a clock-hour counts as 1

Window: Last 28 days (672 hours)

License Types

FCS Runtime: Cloud VMs + EDR

FCS CNAPP: VMs + CSPM/ASPM

FCSC: Container hosts

FMC: Managed containers

Why Use Tags?

Cost allocation, not license counting

• Department: Finance, Engineering

• Environment: Prod, Dev, Test

• Team: TeamA, TeamB

Note: Tag totals exceed CID total because multi-tagged hosts count in each tag
