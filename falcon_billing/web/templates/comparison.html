How This Comparison Works

Scenario A: All EPP

Takes the daily peak total sensor count for each of the last 7 days, then averages.

This is how EPP licensing works — weekly average inflates the count because every sensor seen in a day counts once.

Scenario B: FCS Split

FCS/FCSC/FMC: 28-day hourly average (672 hours). Ephemeral VMs that spin down at night reduce the average.

EPP: 7-day weekly average of daily peaks (physical endpoints are always-on, so method doesn't matter much).

Why FCS Benefits Ephemeral Workloads

Cloud VMs and containers scale up/down. Hourly averaging captures this — a VM running 12h/day counts as 0.5, not 1.

EPP endpoints (laptops) are always-on, so the averaging method barely changes the count.
